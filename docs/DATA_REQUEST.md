# Какие дополнительные данные повысят качество

В исходном архиве уже 313 млн строк. Сейчас модель учится на сгруппированных сигналах датчиков; подтверждённых физических инцидентов в разметке нет. Больше строк того же журнала полезно прежде всего для новой проверки во времени. Более ценный источник для обучения — журнал подтверждённых инцидентов и работ.

## Минимальный журнал инцидентов

Одна строка на реальный инцидент, с привязкой к `object_id` из предоставленного справочника.

| Поле | Значение |
|---|---|
| `incident_id` | Устойчивый идентификатор для устранения дублей |
| `object_id` | Идентификатор объекта из справочника |
| `kind` | Неисправность, пожар, подтопление, нарушение доступа |
| `started_at` | Фактическое начало, если оно известно |
| `detected_at` | Первое обнаружение оператором или системой |
| `confirmed_at` | Когда исход был подтверждён и мог стать известен модели |
| `outcome` | Подтверждённый инцидент / ложное срабатывание / проверка не завершена |
| `resolved_at` | Время устранения, если известно |
| `channel_ids` | Связанные каналы, если известны |

Для всех дат нужны часовой пояс и точность времени. Если начало известно приблизительно, полезны границы интервала. Отсутствие записи нельзя автоматически считать отсутствием инцидента: нужны описание полноты журнала и периоды, когда он велся.

## Работы и оборудование

Для каждой работы полезны объект, тип, начало/окончание, время регистрации и признак плановости. Это позволит отделять регламентные переключения от аварий, учитывать восстановление после ремонта и проверять ложные предупреждения. Для оборудования полезны даты установки и замены, тип, модель и история привязки канала к объекту.

## Новая проверка

Телеметрия после июня 2026 и подтверждённые исходы за тот же период дадут ещё не использованный временной тест. Перед его открытием нужно зафиксировать веса, пороги, правила повторных предупреждений и метрики. Нельзя сначала подобрать на нём модель, а затем назвать результат независимой проверкой.

Чужие наборы отказов двигателей и станков напрямую не объединяются с московскими журналами: у них другие датчики, события и условия. Новые данные в текущие исследовательские результаты не добавлялись.
