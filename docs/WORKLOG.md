## Важные ограничения

Оцениваются сигнальные эпизоды, не подтверждённые физические аварии. Низкая полнота требует применения как дополнительного инструмента. Географических координат нет; используется условная схема. Разовые импорты независимы; накопительный API сохраняет поток в собственной БД. Настоящая СМВУ подключается на пилоте. Метрики замороженной политики не пересчитываются при изменении UI-порогов.
