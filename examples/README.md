# Примеры данных

Все файлы — фрагменты реального архива СМВУ за 15 июня 2026 года. Стенд дополняет их историей из `vercel_runtime/`, поэтому прогноз считается по полной неделе.

| Файл | Формат | Как использовать | Результат |
|---|---|---|---|
| `smvu_journal_2026-06-15.csv` | Журнал СМВУ в формате выгрузки: `ид_события, ид_канала_данных, дата, время, значение_датчика, тревожное` | «Аналитик» → «Данные и загрузка» → «Загрузить и рассчитать», момент не указывать | Прогноз на 15.06 12:00, 312 прогнозов, предыстория 168 ч |
| `smvu_journal_2026-06-15.xlsx` | Тот же час в XLSX | Так же | То же |
| `api/stream_2026-06-15T12-05.json` | Контракт API: `{"events": [{channel_id, ts, value, alarm}]}` | `POST /api/stream/events?format=json&as_of=2026-06-15T12:05` | Пакет потока СМВУ, прогноз на 12:05 попадает в очередь диспетчера |
| `api/stream_2026-06-15T12-10.xml` | Контракт API: `<events><event>…</event></events>` | `POST /api/stream/events?format=xml&as_of=2026-06-15T12:10` | Следующий пакет, прогноз на 12:10 |

Пакеты потока принимаются по возрастанию момента: сначала JSON, затем XML. Для отправки нужна учётная запись с правом загрузки данных (в демо — `analyst`, пароль `contour-demo`). Поток целиком за выбранный интервал воспроизводит `scripts/emulate_smvu.py`.

Свои журналы загружаются так же, как CSV-пример. Для полного прогноза нужна неделя данных до момента прогноза; при меньшем объёме (от суток) прогноз выдаётся с пометкой неполной предыстории.
